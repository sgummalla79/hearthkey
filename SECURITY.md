# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report privately using GitHub's "Report a vulnerability" (Security tab → Advisories) on this repository.

Include: affected component, steps to reproduce, impact, and any proof of concept. Do not include real user data.

## What to expect

- Acknowledgement of your report within a few business days
- A status update as the issue is triaged and fixed
- Credit in the release notes if you want it

## Scope

Hearthkey is zero-knowledge: the server stores only ciphertext. Reports about cryptography, authentication, sharing, recovery, the browser extension, and the mobile apps are the highest priority.

## Supported versions

Only the latest production release receives security fixes.
